# Plexory Releases

Plexory 공식 릴리즈 배포 및 자동 업데이트(auto-updater) 엔드포인트 저장소입니다.

## 다운로드

최신 버전은 [Releases](https://github.com/koleeit/plexory-releases/releases/latest) 에서 받을 수 있습니다.

| 플랫폼 | 파일 |
|--------|------|
| macOS (Apple Silicon / Intel) | `.dmg` |
| Windows | `.msi` |
| Linux | `.AppImage` |

## 자동 업데이트

Plexory 앱은 이 저장소의 `latest.json`(updater manifest)을 통해 자동 업데이트를 확인합니다.

> 소스 코드는 비공개 저장소에서 관리되며, 이 저장소는 배포 아티팩트 전용입니다.
